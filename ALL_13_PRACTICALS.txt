# P1: Project Folder and Terminal Navigation

## Aim
To create a structured web development project directory and navigate between folders using terminal commands.

==> P01_Terminal_Navigation/commands.sh <==
#!/bin/bash
# P1: Project folder and terminal navigation
pwd
mkdir -p web-dev-lab/portfolio/assets
cd web-dev-lab/portfolio
touch index.html style.css script.js
ls -la
cd ..
tree || ls -R
